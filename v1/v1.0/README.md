# Lunch Countdown

Version: 1.0

## Overview

The Lunch Countdown application is a desktop-based Python application built using Tkinter.

The application displays:

- Current Time
- Lunch Time
- Time Remaining Until Lunch

The display automatically refreshes every second using a live countdown timer.

---

## Features

### Current Time Display

Displays the current local system time.

### Lunch Time Display

Displays the configured lunch time.

### Countdown Timer

Calculates the difference between the current time and lunch time.

Displays:

HH:MM:SS

### Automatic Updates

The countdown refreshes every second.
