# Lunch Countdown

Version: 2.0

## Overview

Version 2.0 introduces the application's customization framework.

The focus of this version is establishing a scalable settings architecture for future color customization, loadouts, live preview functionality, and user personalization.

---

## New Features

### Audio System

- Windows button click sounds
- Toggleable sound effects

### Toggle Settings

- Enable Button Click Sounds
- Enable Live Preview
- Always On Top

### Modular Settings Architecture

Settings are now organized into groups:

- Lunch
- Audio
- Toggles
- Colors

### Expanded Settings Window

Added:

- Audio Settings
- Toggle Settings
- Loadout Management placeholder
